📊 Project Description

Vrinda Store Sales Analysis | Excel Dashboard

This project focuses on analyzing Vrinda Store sales data using Microsoft Excel to identify customer behavior, sales trends, and key business insights.

🔍 Key Insights
Women customers contribute around 65% of total purchases.
Maharashtra, Karnataka, and Uttar Pradesh are among the top contributing states.
Customers aged 30–49 years contribute around 50% of sales.
Amazon, Flipkart, and Myntra are major contributing sales channels.
💡 Business Recommendation

The analysis suggests focusing on women customers aged 30–49 years from the top-performing states and promoting offers, discounts, and coupons through major e-commerce channels such as Amazon, Flipkart, and Myntra.

Microsoft Excel
Data Cleaning
Data Analysis

Project Goal:
To transform raw sales data into meaningful insights that can support data-driven business decisions.
